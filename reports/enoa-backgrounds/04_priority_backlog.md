# Очередь исправлений — предложения, не выполненные изменения

Индивидуальный реестр: [issues.csv](issues.csv), [issues.json](issues.json). 99 замечаний относятся к отдельным записям и иногда повторяют общий дефект связанной механики. Не трактовать их как 99 независимых уникальных причин.

P0 — потеря данных/неработающий основной поток. P1 — существенные правила, баланс, противоречие канону. P2 — ясность, интеграция и оставшаяся проверка. P3 — редакционная полировка. BLOCKER/MAJOR/MINOR/EDITORIAL обозначают серьёзность отдельного наблюдения, приоритет партии может быть выше для общего риска.

## P3: индивидуальная редактура

Каждая запись имеет собственное замечание, без механического удлинения текста. Сначала причинные ошибки (`mithras-picker`), затем конфликтующие роли (`dangun-secret`, `hakar`), затем единообразие терминов, затем ритм и повтор. Имена богов/народов не исправлять как обычные опечатки без источника.

Рекомендуемый следующий шаг — закрыть канонические вопросы **пяти пилотов**, затем отдельным запросом выполнить этап C в `proposals/`. После согласования стандарта обрабатывать партии по 5–10 связанных записей: сначала правила 2014 и категориальные исключения, затем самые рискованные Origin, затем институциональные/религиозные сюжеты, затем ремесленные/дорожные. Массовой замены исходников сейчас нет.
