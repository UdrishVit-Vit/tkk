# Бегущий по Спирали — внесение переработки на сайт

31.10.2026. Прямое указание автора: «Внеси обновленные изменения на сайт Бегущий по спирали». Обновлены рабочие данные сайта; удалённое развёртывание www.enoa.club не выполнялось.

Сохранены ID предыстории `spiral-runner` и двух связанных черт. Добавлены история йондани, ограничение «Мор’хор — Дитя Эдры», новые параметры, варианты прошлого, зацепки и стартовое снаряжение. Авторское уточнение о принадлежности йондани к Детям Эдры имеет приоритет над отменённым толкованием об их противостоянии.

«Путь к ядру» заменён чертой «Наследие Спиралей» версии 0.6.0. Для 2024: дополнительное владение навыком и ограниченная реакция с к6 к спасброску Ловкости владельца либо видимого существа в пределах 30 футов. Для 2014: отдельная приобретаемая черта с +1 Ловкости или Интеллекта и двумя применениями реакции между продолжительными отдыхами. Предыстория 2014 автоматически не создаётся и не выдаёт эту черту. Свойства вида, заряды йоргала и их восстановление не изменены.

## Проверки

- `check-backgrounds-2024.mjs`: 54 предыстории, 0 ошибок.
- `check-enoa-origins.mjs`: 54 индивидуальные привязки, четыре регрессионных сценария пройдены.
- `test-backgrounds-2024.mjs`: 19 сценариев отклонения некорректных данных пройдены.
- `test-enoa-authored-feats-v4.mjs` и `test-house-of-knots.mjs`: пройдены. Исторические проверки учитывают эту авторскую переработку и проверяют её соответствие проекту; остальные записи проверяются по прежним снимкам.
- Число записей не увеличилось. Хеши всех записей вне выбранной предыстории и её двух черт совпали с состоянием до переноса.
- Вступление — 30 слов; история — 195 слов и три абзаца. Снаряжение с 14 зм 4 см составляет 50 зм; самостоятельная проверка цен по официальной таблице сохранена в первоначальном REVIEW проекта.
- Визуальная проверка не завершена: браузерный сервис возвращает `browser.user is unavailable` и не позволяет управлять вкладкой. Доступность инвентаря браузера не считается проверкой отображения карточки.

Игровой плейтест и производственная сборка не проводились. Approved означает разрешённое автором включение в каталог, не официальное подтверждение баланса D&D.
