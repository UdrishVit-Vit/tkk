# Служитель Дома Узлов — добавление в проект

30.10.2026. Автор запросил добавление согласованного материала на сайт. Изменения внесены в локальный проект; удалённая публикация не выполнялась.

## Добавленные записи

| Материал | D&D 2024 | D&D 2014 |
|---|---|---|
| Служитель Дома Узлов | Предыстория; Интеллект, Мудрость, Ловкость; Анализ, Аркана | Предыстория; Анализ, Магия; инструмент и язык |
| Архивная выучка | Черта происхождения: Компетентность и один Жемчужный узел | Не выдаётся; отдельная черта 2014 не создавалась |
| Жемчужный узел | Самостоятельный магический предмет | Тот же предмет; выдаётся особенностью предыстории |
| Набор узлового письма | Структурированная карточка инструмента | Структурированная карточка набора |

«Инструменты узлового писца» заменены на «Набор узлового письма» во владениях и стартовом снаряжении новой предыстории. Исторические записи других предысторий не переименовывались.

Набор содержит пять групп принадлежностей. Карточка разделена на состав, применение владения, расходные материалы и хранение. Связанные материалы доступны по ссылкам из предыстории, черты, набора и предмета.

Жемчужный узел требует 10 минут исследования с непрерывным контактом. Полный эффект написан в самой карточке; отсылки к заклинанию «Опознание» нет. Узел выдаётся один раз отдельно от оплачиваемого набора А/Б. Редкость и цена узла не назначены. Комплект А с монетами стоит 50 зм; вариант Б — 50 зм.

## Проверки

- `test-house-of-knots.mjs`: выдача предмета, раздельные редакции, состав, бюджет, уникальность ID и разрешение ссылок. Снимок до добавления подтверждает сохранность прежних 55 предысторий 2024 и двух предысторий 2014.
- Строгая проверка предысторий, 19 отрицательных сценариев, проверка назначений Origin и сохранности прежних черт пройдены.
- Вывод настоящих компонентов проверен через Vue SSR: 56 предысторий, 147 черт 2024, 69 черт 2014; тексты и ссылки сохранены.
- В браузере на локальном сервере проверены все семь новых карточек: раскрытие, переходы из предыстории к набору и предмету в обеих редакциях, поиск «Жемчужный» и фильтр источника TVV. После загрузки JSON каталог магических предметов 2024 содержит 561 запись.
- При ширине 390 пикселей состав набора 2014 отображается одной колонкой; ширина содержимого равна ширине страницы, горизонтальной прокрутки нет. Полный мобильный аудит всего сайта не заявляется.
- При первом открытии локального сервера была долгая загрузка. В существующем компоненте ThreadRefPage обнаружены предупреждения Vue о SVG width/height/viewBox; они не мешали проверенным переходам. Этот общий компонент в задаче не изменялся.

Текущее количество: 56 предысторий 2024 и три предыстории 2014. Авторские правила не проходили плейтест; статус добавления в каталог не означает официального одобрения D&D.
