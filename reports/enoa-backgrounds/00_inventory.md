## Фактическая архитектура

Nuxt 4.4.8 / Vue 3.5, статические JS-модули справочников. Nuxt Content используется другими разделами. Для предысторий не найдено внешней CMS, production DB или отдельного API персонажа. Подключение Pinia само по себе не доказывает наличие конструктора; исполняемый движок персонажа и Android-потребитель в обследованном репозитории не найдены.

2014: `app/pages/dnd5e/backgrounds.vue`, параметр `?bg=id`. 2024: `app/components/dnd55e/BackgroundsPage.vue`, параметр `?background=id`. Оболочка списков — `ThreadRefPage`. Категории, навыки, инструменты и предметы 2024 связаны через локальные справочники. 2014 в основном использует строки, `grantsFeat` — название вместо ID.

`content_status` в реестре означает присутствие в локальном каталоге. Поля публикационного статуса/редакции у предысторий явно не заданы; редакция выведена из модуля и маршрута. URL восстановлены по коду, их публичная доступность не подтверждена. Публичный корень сайта доступен; карточки не удалось проверить веб-инструментом и браузером (тайм-аут). Отсутствие веб-выгрузки не использовалось для подсчёта.

Внутри каждой редакции дубликатов ID/названий не найдено. У всех 73 записей 2024 есть `originalName`; у четырёх 2014 его нет. Полноценной второй локализации каталога не обнаружено — английское название не перевод всей карточки. Это не ошибка обязательного поля текущего интерфейса.

Воспроизведение и проверка реестров: `node reports/enoa-backgrounds/verify-audit.mjs`. Генератор читает зафиксированный baseline и проверяет 529 исходных файлов по SHA-256. Проверка подтверждает 77 файлов с семью аспектами, локальные ссылки и ровно два известных структурных исключения; результат — [verification.json](verification.json). Его JSON/CSV — отчёты, не новый источник данных для сайта. [Реестр исходников лора с SHA-256](baseline/lore-sources.json) позволяет воспроизвести локаторы на тех же версиях.
