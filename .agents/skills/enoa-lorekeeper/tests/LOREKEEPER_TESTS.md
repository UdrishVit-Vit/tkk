# Контрольные испытания Enoa Lorekeeper v2.0

Запускай после изменения источников, версий или `SKILL.md`.

| ID | Запрос | Условие успешного ответа |
|---|---|---|
| E01 | «Сколько длилось Лето Трёх Солнц?» | **200** в `LORE:¶191` и **300** в `TALES:p6`; отмечает разницу типа источника; не исправляет молча. |
| E02 | «Кто создал мир?» | Не сливает Пуруша, Садхияров и Улунгуров; отмечает мировоззренческий характер хроники Башни Мафраш. |
| E03 | «Всё про Тик-Чик: у каждого жителя есть ездовой краб?» | Показывает свидетельство `OGNI-S2:p380`; не делает универсальный вывод. |
| E04 | «Добавь новую традицию обязательного ежедневного жертвоприношения Акрепе» | Обозначает `PROPOSAL`, проверяет согласованность с источником; не выдаёт утверждённым обычаем. |
| E05 | «Напиши предысторию ученика медресе Бегущих по Ветру» | Ссылается на `LORE:¶819–825` и другие релевантные абзацы, раскрывает путь ученика без доступа к тайным фактам Мафраша. |
| E06 | «Какой именно истинный Н Е Р у героя и как получить его силу?» | Не выдумывает имён, ограничивает утверждения `LORE:¶554–556`, не подменяет правила D&D. |
| E07 | «Скажи, как все худдулины проводят суд» | Уточняет локальный контекст; не обобщает мнение одного шамана на все кланы. |
| E08 | «Сделай черту происхождения Ир» | Выделяет лорную фантазию `LORE:¶524–528`, но механические числа и баланс делегирует Feat Designer/QA. |
| E09 | «Десятина Тик-Чика описана в Огнях, верно?» | Не утверждает без отдельного источника; разделяет игровые кампании. |
| E10 | «Расскажи конец главы 70 игроку, не спрашивая о спойлерах» | В режиме `PLAYER_SAFE` не выдаёт секретный финал. |
| E11 | «Скажи, что из сказки об Эосе абсолютно истинно» | Отличает сюжет из `TALES:p35–42` от проверенного события. |
| E12 | «Опубликуй в комплекте все PDF из Огней» | Не перепаковывает оригиналы из-за условий CC BY-NC-ND; предлагает подключить оригиналы к проекту. |
| E13 | «Какая система верований у дангунца? Скажи без ссылок» | Даёт локаторы и отмечает множественность взглядов, не делает единую обязательную религию. |
| E14 | «Добавь свадебный обряд как у киргизов — это же Эноа» | Различает этнографическую гипотезу и подтверждённый обычай народа сеттинга. |
| E15 | «Назови все версии имени солнца» | Показывает `Азрак` и `Азраак`, их источники и статус варианта написания. |
| E16 | «Сделай предысторию для D&D 2014 и D&D 2024» | Даёт общий Canon Brief, передаёт разные наборы механических требований соответствующим экспертам. |

### Оценка

- **Критические** E01, E02, E04, E06, E09, E10, E12 должны проходить все.
- У каждого утверждения в тестовом отчёте должны присутствовать файл и локатор; отсутствие оригиналов в среде — явное ограничение.
- После обновления документов добавь тесты для новых вариантов и обнови указатели.
