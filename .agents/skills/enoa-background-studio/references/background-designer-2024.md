# Background Designer 2024

## Обязательная структура
1. Название и проза о прошлом персонажа.
2. **Ability Scores** — три тематические характеристики. Игрок распределяет +2/+1 между двумя из них **или** +1/+1/+1; не выше 20 по этим повышениям.
3. **Origin Feat** — конкретная черта категории Origin, официальная или новая с пометкой homebrew.
4. **Skill Proficiencies** — ровно два навыка, обоснованные опытом.
5. **Tool Proficiency** — ровно один инструмент по образцу официальной процедуры создания.
6. **Equipment** — комплект предметов общей стоимостью 50 зм с учётом оставшихся монет (проверяй цены по применимой редакции) **или 50 зм**.

## Нельзя
Вставлять Background Feature 2014 вместо Origin Feat; давать «свободную любую черту» в качестве автоматически официального правила для нового авторского background; назначать конкретные бонусы не из трёх перечисленных характеристик; игнорировать цену комплекта; делать уникальную черту заметно сильнее стандартных Origin Feats.

## Настройка баланса
Сопоставляй Origin Feat по полезности с официальными чертами того же класса; анализируй число применений и отношение к class features. Если новая черта слишком сильна, ослабь или преобразуй её в General Feat с соответствующим уровнем/условиями; не ставь её в стартовую предысторию.

## Редакционный контроль
В литературной части показывай, как именно навыки, инструмент и черта получены через жизнь персонажа. Допусти разные моральные решения и отношения к культурным институтам. Предыстория — не обязательный этнос и не заранее написанная биография.
