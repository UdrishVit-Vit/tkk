# Протокол достоверности и проверки лора

## Два независимых измерения статуса

**Авторское утверждение (authority):**
- `APPROVED_CANON`: автор мира явно утвердил этот тезис/правку для определённой редакции.
- `SOURCE_ATTESTED`: текст есть в определённом источнике, но он может быть WIP, легендой или голосом персонажа.
- `AUTHOR_DRAFT`: проект/рабочая заготовка, автор не утвердил.
- `PROPOSAL`: новая гипотеза ИИ или участника, не включена в канон.
- `UNKNOWN`: первоисточник не найден, информация отсутствует.
- `CONFLICT`: два свидетельства расходятся; **не считать одно ошибкой без решения**.

**Природа свидетельства (evidence_type):**
`LOREBOOK_WIP`, `IN_WORLD_HISTORIAN`, `FOLKLORE`, `CHRONICLE_OBSERVED`, `CHARACTER_CLAIM`, `RUMOR`, `ERA_SPECIFIC`, `PLAYER_CAMPAIGN_ONLY`, `AUTHOR_DIRECT`.

Примеры:
- `У Башни Мафраш Пуруш связывается с Колыбелью и Искрой`: authority `SOURCE_ATTESTED`, evidence `LOREBOOK_WIP+IN_WORLD_HISTORIAN`.
- `Сказители помнят три сотни лет под тремя солнцами`: `SOURCE_ATTESTED + FOLKLORE`, а не установленный календарный факт.
- `Тик говорит, что ...`: `SOURCE_ATTESTED + CHARACTER_CLAIM`; это его слова, не универсальный обычай города.
- `Появление нового ремесла для конкретной деревни Эноа`: `PROPOSAL + ETHNOGRAPHIC_INSPIRATION` (отдельный тип вдохновения).

## Минимальная карточка утверждения

```yaml
id: enoa-001
statement: "..."
entity: "..."
context: "регион / эпоха / социальная среда"
source_locator: "LORE:¶NNN / TALES:pNN / OGNI-S2:pNN"
authority: SOURCE_ATTESTED
evidence_type: [LOREBOOK_WIP]
knowledge_scope: LOCAL_BELIEF
certainty_note: "..."
conflicts_with: []
spoiler_level: PLAYER_SAFE
potential_background_use: "..."
author_approval: null
```

Не дописывай `author_approval=true` от себя. Никакие рейтинги уверенности не заменяют происхождения утверждения.

## Фильтр знаний героя

`WORLD_TRUTH` — то, что установлено Мастером как объективное; `LOCAL_BELIEF` — в обществе принято так считать; `PERSONAL_BELIEF` — конкретный герой так думает; `GM_SECRET` — секрет кампании; `UNKNOWN_TO_CHARACTER` — персонаж не знает.

При формулировке предыстории обыкновенного ремесленника правило: даже если у Мастера есть ответ на космологический вопрос, **не делай персонажа всезнающим**. Передавай сведения через сказки, праздники, споры, семейные клятвы, ремесленную практику.

## Проверка высказывания

Для каждого тезиса:
1. Кто сообщает? Историк, сказитель, авторское описание, игрок, NPC?
2. Что именно сказано: событие, убеждение, слух, оценка, предсказание?
3. Где и когда это происходит?
4. Есть ли контрпример в другом источнике или исключение в той же сцене?
5. Не основано ли суждение на эстетической ассоциации, а не на тексте?
6. Какова точная ссылка (файл/параграф/страница/глава)?
7. Можно ли использовать тезис в предыстории без сюжетообразующего спойлера?

Не использовать маркировку `CANON` как единственный статус. Признать тезис `SOURCE_ATTESTED` не значит утверждать его абсолютную истинность.
