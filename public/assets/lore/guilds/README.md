# Портреты участников гильдий

Каждая гильдия хранится в отдельной папке. Внутри members — отдельная папка для каждого известного участника.

Пример: apple-of-discord/members/riz/portrait.webp
Публичный путь: /assets/lore/guilds/apple-of-discord/members/riz/portrait.webp

После добавления изображения заполните поле portrait в соответствующей записи app/data/loreGuilds.js. Рекомендуется вертикальный портрет 4:5, не меньше 800 × 1000 px. В поле portraitAlt можно добавить описание внешности для экранных дикторов.

Пока portrait равен null, карточка показывает нейтральный силуэт. Портреты народов не используются вместо персональных изображений.

Создано 18 папок участников. У гильдий без известных имён вымышленные участники и папки не добавлялись.
