# Баба Хрун

Гильдия: Слепой Бунти.

Добавьте утверждённый портрет в эту папку (рекомендуемое имя portrait.webp, вертикальный формат 4:5, от 800×1000 px). Затем заполните поле portrait у этого участника в app/data/loreGuilds.js публичным путём к файлу. Поле portraitAlt можно использовать для описания изображения.

До добавления портрета сайт показывает нейтральный силуэт. Внешность персонажа не выдумана.
