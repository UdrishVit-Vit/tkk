# Дизайн-система Узла Узлов

Пилот: «Главная → D&D 2024 → Заклинания» и «Пантеон → Садхияры». Остальные каталоги и статьи не переводятся на новый шаблон автоматически. Общая панель навигации переиспользуется страницами, которые уже работают через `HubPage`.

## Типографика и цвет

- `--ds-serif` (Cormorant Garamond) — заголовки и основной текст лора; `--ds-sans` (Hanken Grotesk) — навигация, редакция, метаданные, фильтры и список справочника.
- Заголовки меняются по масштабу страницы. Служебные подписи по умолчанию — `--ds-label` (12 px), подписи компактной панели — 11 px. Не использовать 6–8 px для навигации и состояния. Просто декоративные индексы могут жить отдельно от функциональных подписей.
- Базовые цвета предоставляет `--theme-*`; роли текста, рамки, активного элемента и фокуса определены в `app/assets/css/design-system.css`. Не задавать новые RGB на каждом экране.

## Оформление по задаче

| Роль | Правило |
| --- | --- |
| Карта (`ds-atlas`) | Узлы и связующие нити поддерживают исследование. На десктопе карту дополняет обычный список: не нужно разгадывать схему, чтобы открыть раздел. |
| Лор (`ds-lore`) | Печать обозначает раздел, нить помогает читать последовательность. Курсив оставляем цитатам. На телефоне компактное оглавление, явная ссылка к родительской странице. |
| Справочник (`ds-reference`) | В центре поиска — название, поле поиска, фильтры и результаты. Сетка и декоративная нить тише текста. Золото показывает важную связь или выбор, а не обводит все элементы. |

## Компоненты и состояния

- `UiActionIcon`: контурные значки одинаковой толщины для действий. Узлы и печати не заменяют кнопку «Назад», поиск и закладку. Для иконки без подписи нужен доступный текст.
- `UiMobileNav`: «Главная → Поиск → Закладки → Системы → Ещё». На страницах хаба панели открываются поверх текущего экрана; из отдельного каталога ссылка открывает ту же панель в его системном путеводителе. Поиск по самому каталогу остаётся в шапке и не подменяет глобальный поиск.
- `UiBreadcrumb`: путь и текущая страница. Действия используют `.ds-control` и `.ds-button`: нейтральный фон, явный фокус, выделение открытого/выбранного, удобная высота. Использовать `aria-expanded`, `aria-pressed` или `aria-current` в зависимости от смысла, а не по внешнему виду.
- Загрузка маршрута — индикатор Nuxt; пустая выдача — текстовое состояние `.ds-empty`, а не пустой фон; число найденного объявляется отдельно. Для анимаций управления учитывать `prefers-reduced-motion`.

## Проверка при переносе на новый раздел

1. На 320, 390 и 1440 px проверить заголовок, видимый путь назад, рабочие действия и отсутствие горизонтальной прокрутки.
2. Проверить клавиатурный фокус, поиск с пустой выдачей, выбор и сброс фильтра, переключение глав. Временно отключить декоративную нить: структура должна оставаться понятной.
3. Не заменять раскладку страницы только ради сходства с другими: переносить компоненты, роли и состояния, а не композицию целиком.
