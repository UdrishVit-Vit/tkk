# Предыстории и черты происхождения Эноа

Актуальная редакция черт — **0.3.0, 25 октября 2026**. Для **57 авторских предысторий** подготовлено по одной уникальной черте: 39 Playtest и 18 Draft. У **16 адаптаций PHB** новые черты не создавались; ранее исправленная узловая письменность сохранена в обоих разделах.

Основные описания авторских предысторий теперь состоят из двух абзацев: культурная среда Эноа и приобретённый опыт. Прежний предел 70–110 слов расширен по просьбе о глубине; тексты занимают примерно 125–159 слов. Узловая письменность общедоступна: профессионал отличается навыком работы со сложными свидетельствами, а не исключительным правом читать.

Книги, бумага, чернила и писчие перья удалены из действующих описаний, зацепок и подписей комплектов. Снаряжение показано как узловые принадлежности; исходные механические ID, цены и параметры сохранены для совместимости. Это адаптация облика, а не новая экономика кипу. Каждый комплект А по-прежнему составляет 50 зм вместе с монетами; Б — 50 зм.

## Статус механик

39 предложений имеют статус Playtest — готовы к ограниченному игровому тестированию; 18 остаются Draft из-за зависимости от редких ситуаций или сложности условий. Для каждой черты есть три концепции, пять аналитических сценариев и разбор уровней 1, 5, 11, 17. Различные названия и условия не доказывают равенство силы. Игровые сессии с участниками не проводились.

Новые черты подготовлены **вместо** действующих назначений, не вдобавок к ним. Опубликованные ссылки и старые механики сохранены до утверждения. Это также сохраняет два прежних исключения категории Free у «Безымянного» и «Крови Хешег». Для них теперь есть индивидуальные Origin-проекты; прежнее предложение заменить их просто на Tough и Skilled больше не является текущим решением.

Официальные и старые авторские черты не удалены. 2014-я редакция не изменялась. Существующие авторские записи со статусом Legacy не становятся утверждёнными автоматически. Закрытые источники и не прочитанные PDF не выдаются за проверенные.

## Файлы и проверки

Действующие описания: `app/data/dnd55e/backgrounds.js`. Проекты: `app/data/dnd55e/origin-feats-enoa-drafts.js`. Реестр связей и защита публикации: `app/data/dnd55e/origin-feats-homebrew.js`.

Статусы новой редакции: Draft → Playtest → Approved; прежний Testing поддерживается для совместимости. Только Approved включается в каталог. После решения автора меняют назначение предыстории и проверяют, не остался ли одновременно прежний дар, предмет или проклятие. Утверждение черты не означает автоматического утверждения других 56 проектов.

- `npm run backgrounds:check` — структура и бюджет; два известных исключения выводятся явно.
- `npm run backgrounds:enoa-check` — 57 отдельных связей, отсутствие проектов PHB, узловая письменность и регрессии.
- `npm run backgrounds:test` — проверки ошибок и сохранности опубликованной механики.
- `npm run backgrounds:render` — компиляция компонентов и вывод их содержимого; не заменяет браузер.
- `npm run backgrounds:origin-check` — полнота 57 досье, расчёты, статусы и соответствие текстов реестру.
- `npm run backgrounds:origin-review` — обновляет третью редакцию и реестр проектов из сохранённых авторских материалов.
- `npm run backgrounds:check:strict` — намеренно не допускает два сохранённых исключения Free.
- `npm run backgrounds:report` — прежний генератор реестров и отчётов второй редакции; не является генератором третьей редакции.
