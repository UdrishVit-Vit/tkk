## Что изменено

Вместо преимущественно лорных справок основные абзацы описывают занятия, обучение и применение опыта. Новые тексты не назначают обязательных чувств, моральной позиции или будущей цели. Краткие аннотации приведены в соответствие с ними. Существующие варианты биографии и таблицы событий сохранены как необязательные возможности; длинные прежние описания доступны в раскрываемом разделе. Полная исходная редакция каждой записи сохранена в аудите.

Исправлены пояснения к механике: три владения от Skilled вместо двух, зависимость ресурса Lucky и числа получателей Musician от бонуса мастерства, отсутствие гарантированного первого хода от Alert, расход Костей хитов получателя лечения, ограничения Savage Attacker и различие Атлетики/Акробатики. Официальные тексты и эффекты черт не переписывались.

Снаряжение структурировано по количеству и цене в медных монетах; каждый набор А с монетами составляет 50 зм, вариант Б также 50 зм. Дорогое увеличительное стекло исключено из стартовых наборов; инструменты стоимостью 50 зм занимают весь бюджет А. Воинское длинное копьё заменено простым. Для позиций с переменной ценой выбран конкретный вариант комплекта. Это адаптации комплектов для Эноа, не заявление о буквальном воспроизведении комплекта PHB. Владение инструментом по выбору не изменено.

Авторские инструменты татуировщика и обо заменены в соответствующих предысториях стандартными инструментами художника и каменщика. Сам каталог снаряжения и его авторские инструменты сохранены. Уникальные детали истории больше не объявляются бесплатными предметами: наличие и цена согласуются отдельно, а предметы от существующих черт выдаются по их правилам.

## Что остаётся открытым

**Две существующие предыстории не соответствуют категории Origin:** «Безымянный» и «Кровь Хешег» используют свободные черты. ТЗ требует сохранять рабочие опубликованные версии при спорных изменениях, поэтому они не заменены и не переименованы в Origin. Предложены Tough и Skilled соответственно, но это решение автора. Строгая проверка намеренно возвращает ошибку до разрешения этих двух вопросов.

Двенадцать существующих авторских Origin-черт отмечены как Legacy: ранее опубликованные, без подтверждения баланса этой работой. Риски и направления правок перечислены в balance.md. Новые «Память путей», «Память узла» и «Глаз оценщика» имеют статус Draft. Первую и третью можно выносить на игровой тест; вторая требует доработки полезности. Ни одна не назначена персонажу автоматически. Реальный плейтест с участниками не проводился.

Цены уникальных сюжетных предметов не придуманы: их список по каждой предыстории находится в equipment.md. Сохранены опубликованные канонические опоры. Работа опиралась на тексты репозитория; дополнительные DOCX/PDF из Downloads и EnoaTranscripts не понадобились и не использовались как подтверждение новых фактов. Обычные рабочие занятия в новых абзацах — редакторская конкретизация опыта персонажа, а не новые законы мира, организации или исторические события.

## Редактирование и утверждение

Предыстории редактируются в `app/data/dnd55e/backgrounds.js`; новые черты — в `app/data/dnd55e/origin-feats-homebrew.js`. Поля черты: ID, название, категория, источник, статус, краткое описание, предпосылки, повторяемость, преимущества, действие, условия, лимит, восстановление, связанные предыстории. Предложения связываются отдельно через `DND55E_BACKGROUND_FEAT_PROPOSALS`; поле `background.feat` остаётся единственным назначением опубликованной черты.

Статусы новых черт: Draft → Testing → Approved. Только Approved включается в публичный `DND55E_FEATS`; перевод выполняется после авторского решения и записи результатов тестирования. Затем можно отдельно заменить `background.feat` на утверждённый ID и обновить игровые пояснения. Новую черту нельзя выдавать вдобавок к прежней за тот же слот. Для официальных черт используется Official, для ранее опубликованных авторских — Legacy; Legacy не назначается новым черновикам.

Проверки: `npm run backgrounds:check`, `npm run backgrounds:test`, `npm run backgrounds:check:strict`. Обычная проверка допускает только два явно перечисленных старых исключения, любое новое несоответствие останавливает сборку. Строгая не допускает и их. `npm run backgrounds:report` обновляет производные реестры из игровых данных; before.json и audit-before.md не обновляются. `prebuild` запускает проверку автоматически. Никакой автоматический тест не объявляет черту сбалансированной.

## Нормативные источники

Проверены открытые официальные материалы; закрытые полные тексты PHB и DMG не выдаются за прочитанные. Не использовались материалы Unearthed Arcana 2022 как правила финальной редакции.

- [Character Origins, Basic Rules 2024](https://www.dndbeyond.com/sources/dnd/br-2024/character-origins) — структура, повышение характеристик и открытые примеры.
- [Creating a Background, DM’s Toolbox](https://www.dndbeyond.com/sources/dnd/br-2024/dms-toolbox#CreatingaBackground) — выбор компонентов, бюджет и запрет воинского оружия/доспехов.
- [Feats, Basic Rules 2024](https://www.dndbeyond.com/sources/dnd/br-2024/feats) — открытые игровые формулировки.
- [Официальный обзор Origin-черт PHB 2024](https://www.dndbeyond.com/posts/1785-the-backgrounds-and-origin-feats-in-the-2024) — состав десяти эталонных черт.
- [Equipment, Basic Rules 2024](https://www.dndbeyond.com/sources/dnd/br-2024/equipment) — цены, типы инструментов и оружия.
- [SRD 5.2.1](https://www.dndbeyond.com/srd) — открытая нормативная база; лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Материал правил, включённый из System Reference Document 5.2.1, принадлежит Wizards of the Coast LLC и доступен по Creative Commons Attribution 4.0 International. Русские редакционные тексты и проектные черты Эноа написаны для этой работы. Ссылка на PHB сама по себе не распространяет лицензию SRD на материалы, отсутствующие в SRD; новая работа не расширяет разрешения на прежние тексты репозитория.
