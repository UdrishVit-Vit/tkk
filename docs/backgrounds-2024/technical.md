# Технический отчёт

Работа: 23–24 октября 2026. Исходное рабочее дерево было чистым. Разрушительные операции Git не выполнялись, коммит и публикация не создавались.

## Изменённые игровые файлы

- `app/data/dnd55e/backgrounds.js`: 73 описания и аннотации, исправления игровых пояснений, 14 архивных лорных разделов, структурированные комплекты, три исправления владения инструментом, простое копьё вместо воинского; ID, характеристики, навыки и ссылки на существующие черты сохранены.
- `app/data/dnd55e/feats.js`: метаданные Official/Homebrew и Official/Legacy; подключение только Approved из нового реестра. Механические поля существующих черт не изменены.
- `app/data/dnd55e/origin-feats-homebrew.js`: три полных Draft, отдельные проектные связи с предысториями, предикат публикации только Approved.
- `app/components/dnd55e/BackgroundsPage.vue`: обозначение авторской механики и двух исключений Free, архивный лор в details, объяснение набора А, исправление подписи характеристик (предел 20), поиск по лору и сюжетным деталям.
- `app/components/dnd55e/FeatsPage.vue`: различение ранее опубликованных авторских и утверждённых черт.
- `package.json`: команды проверки, строгой проверки, тестов, генерации отчётов и автоматический prebuild.

## Проверки данных

`scripts/lib/validate-backgrounds-2024.mjs` возвращает список ошибок, включая отсутствующий/повторный ID, пустое описание, отсутствующую/неразрешимую ссылку на черту, неверную категорию, количество и повторы характеристик/навыков, неизвестный инструмент, альтернативу 50 зм, цену и сумму комплекта, расхождение текстовой суммы монет, обязательные поля авторской механики, ссылки проекта и публикацию Draft/Testing. Внутренние ссылки на глоссарий и снаряжение проверяются по фактическим каталогам.

Цены проверяются не только сложением: стоимость каждого предмета сверяется с каталогом, а варианты переменных позиций — с явной таблицей. Расчёт ведётся целыми медными монетами. Сюжетные детали не считаются бесплатной частью комплекта; отсутствие их цены открыто отражено в отчёте.

`scripts/check-backgrounds-2024.mjs` допускает только две точные прежние пары «ID предыстории → Free-черта». Это не общая поблажка для категории Free. `--strict` возвращает ненулевой код и для этих исключений. В ходе обычной проверки они выводятся как PENDING APPROVAL, а не скрываются.

`scripts/test-backgrounds-2024.mjs` подставляет 19 ошибочных вариантов, проверяет их обнаружение, проверяет запрет публикации Draft/Testing/Legacy из нового реестра и сравнивает механические поля связанных старых черт с исходным снимком. Проверяется сохранность каждой опубликованной ссылки на черту. Это проверки данных и регрессий, а не тесты игрового баланса.

`scripts/report-backgrounds-2024.mjs` создаёт текущие реестры, расчёты комплектов и вероятностей. `scripts/report-backgrounds-before.mjs` воспроизводит исходный аудит из неизменяемого снимка. Одноразовые миграционные файлы после применения удалены; редактируются игровые данные, а не промежуточные копии текстов.

Промежуточная сборка была остановлена после дальнейших исправлений игровых пояснений; следующий сеанс прервался до завершения упаковки. При возобновлении проверено отсутствие старого процесса и обойдена оставшаяся блокировка Nuxt. Ограниченная среда препятствовала загрузке шрифтов (EACCES); повторный разрешённый запуск завершился успешно, шрифты загружены и закешированы. Финальная сборка выполнена по актуальным данным. Предупреждения зависимостей: sourcemap плагина module-preload, аннотации PURE в VueUse, устаревшие trailing-slash exports у Iconify/Vue. Они не объявляются исправленными этой работой. HTTP-проверка подтверждает запуск и ответы маршрутов, но не работу браузерных фильтров.

## Ограничения результата

`backgrounds:render` компилирует фактические Vue-компоненты страниц и проверяет их HTML с упрощённой оболочкой каталога. Эта проверка не заменяет проверку расположения элементов, интерактивного поиска и гидратации в браузере.

Полное соответствие всех предысторий категории Origin не заявляется до решения по двум старым Free-чер­там. Баланс существующих Legacy и новых Draft не считается окончательно подтверждённым. Все разрешённые ТЗ изменения выполнены без автоматического утверждения спорной механики. Отчёты отдельно показывают эти ограничения, чтобы успешная обычная проверка не воспринималась как одобрение правил кампании.
